# Portfolio – Łukasz Janicki

Osobiste portfolio zbudowane w **Vue 3 + Vite**. Prezentuje moje projekty, umiejętności i doświadczenie zawodowe.

🔗 [Mafu2k na GitHub](https://github.com/Mafu2k)

---

## Stack

| Warstwa      | Technologie                          |
|--------------|--------------------------------------|
| Framework    | Vue 3                                |
| Bundler      | Vite                                 |
| Animacje     | GSAP + ScrollTrigger                 |
| Język        | JavaScript                           |

---

## Uruchomienie lokalne

```bash
# zainstaluj zależności
npm install

# serwer deweloperski (http://localhost:5173)
npm run dev

# build produkcyjny
npm run build

# podgląd buildu
npm run preview
```

---

## Struktura projektu

```
portfolio/
├── src/
│   ├── App.vue      # cała aplikacja – sekcje hero, o mnie, projekty, kontakt
│   ├── main.js      # punkt wejścia Vue
│   └── style.css    # style globalne
├── index.html
├── vite.config.js

```
